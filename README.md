# HDFC Mutual Fund Facts Assistant

**Selected assignment product: Groww.** This independent classroom prototype answers factual questions about five HDFC schemes using official HDFC sources. It is not affiliated with Groww or HDFC Mutual Fund.

The setup guide, [17-URL source list](artifacts/facts-only-mf-assistant/docs/sources.md), sample Q&A, and disclaimer are in the [project README](artifacts/facts-only-mf-assistant/README.md). No credentials, private account data, or local Chroma database are included.
